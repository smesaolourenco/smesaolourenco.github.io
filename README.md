# Sistema de Certificados — Formação Continuada

**Secretaria Municipal de Educação de São Lourenço do Oeste – SC**

Sistema web para gestão da Formação Continuada dos profissionais da Rede Municipal de Ensino: cadastro de formações e encontros, controle de presença, cálculo da carga horária individual e emissão de certificados com código de validação.

## Acesso

- **Portal do professor e validação de certificados:** https://smesaolourenco.github.io/portal.html
- **Sistema administrativo:** uso restrito da Secretaria Municipal de Educação

Para conferir a autenticidade de um certificado, leia o QR Code impresso no documento ou digite no portal o código de validação. A tela de validação confirma os dados do certificado; a cópia do documento é obtida somente pelo titular, com CPF e senha no portal.

## Situação do projeto

Sistema em uso interno pela Secretaria Municipal de Educação, em fase de implantação.

Este repositório é público porque a hospedagem é feita pelo GitHub Pages. **Nenhum dado pessoal fica armazenado neste repositório**: as informações de professores, formações e certificados ficam em banco de dados externo.

Está prevista para as formações de 2026 uma nova versão com reforço no controle de acesso e na proteção de dados pessoais, em adequação à Lei Geral de Proteção de Dados (Lei nº 13.709/2018).
